# Synthetic fixtures

`demo_data.json` is a fixed, fully synthetic configuration for two Indian small-business demonstrations. It contains no real personal, banking, or merchant data. The seed command expands it into six months of transactions, invoices, counterparties, obligations, and relationship records.

The examples include raw duplicate candidates, unmatched records, and repeated use of a supplier so later analytics can derive evidence quality. They do not encode approval, denial, fraud, or default conclusions.
